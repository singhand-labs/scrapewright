Enhanced Scraping Mode

Not enabled
Complementary layer: transiently attaches chrome.debugger to scrape tabs and issues Page.setWebLifecycleState(active) to lift Chrome's page-lifecycle throttle.

Limitation: this toggle addresses the page-lifecycle layer but not the compositor frame-production layer. For sites with lazy-load (Facebook feeds, infinite scroll, virtualized lists), IntersectionObserver callbacks still won't fire on background tabs because no frame is produced. For reliable background-tab scraping on such sites, run: scrapewright throttle on and restart Chrome — this sets Chrome launch flags (--disable-renderer-backgrounding and friends) that disable frame-production throttling at the process level.

The debugger permission is granted at install time (Chrome does not allow it as an optional permission); this toggle controls whether the extension actually uses the debugger at runtime. While enabled, Chrome will briefly show a yellow "extension is debugging this browser" banner each time a scrape tab opens (transient, <100ms). Detection-risk minimized: only Page.setWebLifecycleState is issued, never Runtime.evaluate.
