LLM Configuration

Per-request timeout for LLM calls. Blank = 120s. Increase if your model is slow; lower for faster failure.

Completion token budget for every LLM call (max_tokens). Blank = 8192. Raise it if your model spends tokens on reasoning or truncates long JSON outputs (finish_reason=length).

Server Configuration

The port must match scrapewright install --port=N. For a local multi-instance setup, every Chrome Profile must use its own host port (basePort + instance ID) and contain its own imported or created services; profiles do not share extension data.

Enhanced Scraping Mode

Not enabled
Enables trusted wheel and hover input when normal DOM events are insufficient. The extension attaches chrome.debugger only while dispatching the required Input.* event.

Scrape tabs are activated when rendering or trusted input requires it and remain active until the scrape tab closes or you select another tab. Your last manually selected tab is restored when the scrape tab closes. Enhanced mode is useful for lazy loaders and hovercards that ignore synthetic JavaScript events; ordinary scraping does not need it.

The debugger permission is granted at install time (Chrome does not allow it as an optional permission); this toggle controls whether the extension actually uses the debugger at runtime. Chrome may briefly show an "extension is debugging this browser" banner when a trusted wheel or hover event is sent. Only Input.dispatchMouseEvent is used; the extension does not issue Runtime, Network, DOM, or Emulation commands through this feature.

If a site still throttles timers or rendering, run scrapewright throttle on and restart Chrome. This optional host setting adds process-level anti-throttling flags and is separate from trusted input.
